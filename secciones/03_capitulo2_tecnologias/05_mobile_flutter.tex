\subsection{2.5. Desarrollo Móvil Multiplataforma con Flutter}\label{sec:mobile_flutter}

\subsubsection{2.5.1. Framework Flutter y Lenguaje Dart}\label{sec:flutter_dart}

Flutter es el toolkit de UI de Google para crear aplicaciones compiladas nativamente para móvil, web y escritorio a partir de un único código base escrito en Dart \parencite{windmill2020flutter}. Permite una tasa de refresco elevada y un rendimiento cercano al código nativo en dispositivos Android e iOS.

\subsubsection{2.5.2. Arquitectura Móvil para Carga Remota de Expedientes Digitales}\label{sec:flutter_carga_expedientes}

La arquitectura de la app móvil organiza la lógica de negocio y la captura de datos (fotografías de documentos socioeconómicos y formularios) facilitando que los estudiantes postulen remotamente sin saturar las instalaciones físicas de la universidad \parencite{esposito2021mobileenterprise}.

\subsubsection{2.5.3. Consumo de APIs y Manejo de Almacenamiento Local}\label{sec:flutter_apis_almacenamiento}

La aplicación utiliza servicios para el consumo asíncrono de las APIs REST de Spring Boot y emplea almacenamiento local en el dispositivo para gestionar sesiones de usuario de forma segura y permitir el guardado borrador de la postulación \parencite{decarli2021flutter}.
