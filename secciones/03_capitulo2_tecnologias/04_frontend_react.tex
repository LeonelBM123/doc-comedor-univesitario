\subsection{2.4. Desarrollo Web Frontend con React y TypeScript}\label{sec:frontend_react}

\subsubsection{2.4.1. Biblioteca React con TypeScript para Aplicaciones Web Escalables}\label{sec:react_typescript}

React es una biblioteca JavaScript orientada a la construcción de interfaces de usuario basadas en componentes reutilizables y un DOM virtual que optimiza el rendimiento del renderizado \parencite{banker2014react}. Al integrar TypeScript, se añade un tipado estático que reduce los errores en tiempo de desarrollo y mejora la mantenibilidad del código del panel web \parencite{cherny2019typescript}.

\subsubsection{2.4.2. Gestión de Estado Asíncrono y Caché con TanStack Query}\label{sec:react_tanstack_query}

TanStack Query (anteriormente React Query) es una librería especializada en la gestión del estado del servidor en aplicaciones frontend \parencite{linsley2021tanstack}. Optimiza el rendimiento mediante el almacenamiento en caché, la sincronización automática y la eliminación de peticiones HTTP duplicadas durante la revisión masiva de carpetas por los auditores.

\subsubsection{2.4.3. Diseño de Interfaces de Usuario para Paneles de Auditoría y Control}\label{sec:react_ui_paneles}

El diseño de la interfaz web prioriza la usabilidad y la \textit{scannabilidad} visual, permitiendo a las trabajadoras sociales auditar los expedientes priorizados por la IA, revisar respaldos y gestionar el listado de los 900 becados de manera intuitiva \parencite{tidwell2020designinginterfaces}.
