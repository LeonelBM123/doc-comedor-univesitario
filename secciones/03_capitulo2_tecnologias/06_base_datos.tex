\subsection{2.6. Sistema de Gestión de Bases de Datos}\label{sec:base_datos}

\subsubsection{2.6.1. Base de Datos Relacional PostgreSQL}\label{sec:postgresql}

PostgreSQL es un sistema de gestión de bases de datos relacional orientada a objetos (ORDBMS) de código abierto, reconocido por su fiabilidad, integridad de datos y soporte para transacciones complejas compatibles con ACID \parencite{riggs2015postgresql}.

\subsubsection{2.6.2. Modelado de Datos, Integridad Referencial y Consultas Masivas}\label{sec:modelado_datos}

El diseño relacional mediante esquemas bien estructurados y claves foráneas garantiza la consistencia entre los registros de estudiantes, solicitudes socioeconómicas y asistencias al comedor. Además, sus índices optimizados permiten ejecutar consultas masivas de forma rápida durante la fase de postulación \parencite{chodorow2013mongodb}.
